# Pin photos

The demo uses `placeholder-seeker.svg` and `placeholder-hider.svg`. Replace
them with your own images and point `seekers.photo` / `hider.photo` in the
scene at the new files.

Scene paths are repo-root-relative, for example
`assets/images/my-seeker.jpg`. Square images crop best; the pin renders a
circle with a colored border and a spike below it.
